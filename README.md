# ◆ ДЕРЖАВА

Браузерная пошаговая геополитическая стратегия с углублённой экономикой и политикой.
Вымышленный мир из 10 государств, 2030–2055 годы, один ход — один месяц.

Игра целиком работает в браузере (чистый JavaScript, без сборки и зависимостей), сохранения — в `localStorage`.

## Что внутри

**Экономика**
- 5 секторов (АПК, промышленность, услуги, хай-тек, добыча) со своим ростом потенциала
- Разрыв выпуска, кривая Филлипса, инфляционные ожидания, закон Оукена
- Центробанк: ручная ставка, автопилот по правилу Тейлора или независимый ЦБ (закон); денежная эмиссия
- Плавающий курс, реальная девальвация, резервы, валютные интервенции
- Бюджет: 6 налогов (НДФЛ, взносы, прибыль, НДС, НДПИ, пошлины) и 10 статей расходов; собираемость зависит от коррупции и налоговой нагрузки
- Госдолг, рыночная ставка по долгу, кредитный рейтинг, долговые кризисы и дефолты
- Мировые рынки нефти, газа, металлов и зерна: цены — из спроса и предложения всех стран
- Торговля по гравитационной модели: соглашения, санкции, войны и отношения меняют доступ к рынкам
- Индексы образования, здравоохранения, инфраструктуры и науки медленно следуют за расходами

**Товарная экономика и торговля**
- 25 товаров в 5 категориях: сырьё (нефть, газ, уголь, руда, медь, редкоземы, лес), агро (зерно, мясо, фрукты, хлопок), промышленность (нефтепродукты, сталь, химия, станки, автомобили, текстиль, потребтовары, продукты, вооружение), хай-тек (электроника, чипы, лекарства), услуги (финансы/IT, туризм)
- Межотраслевой баланс: сталь делают из руды и угля, электронику — из чипов, меди и редкоземов, автомобили — из стали, электроники и чипов и т. д. Дефицит сырья режет выпуск по всей цепочке
- Каждый месяц двусторонние потоки каждого товара распределяются между всеми странами (расстояние, границы, соглашения, блоки, отношения, курс, пошлины, санкции, эмбарго, войны)
- Мировые цены — из спроса и предложения; добыча и специализация стран подстраиваются под цены
- Политика по каждому товару: особая пошлина, экспортная пошлина, запрет экспорта, субсидия производителям, эмбарго против конкретных стран
- Карточка каждого товара: история цены, производители и потребители, все торговые потоки (и стрелками на карте), цепочки «из чего / куда», наша политика
- Торговый профиль каждой страны: что продаём и покупаем, двусторонняя история, взаимная критическая зависимость
- Интерактивные графики: наведите курсор — увидите дату и значения

**Политика**
- 7 социальных групп (рабочие, аграрии, бизнес, интеллигенция, пенсионеры, силовики, молодёжь) — у каждой свои интересы
- 5 партий, парламент на 100 мест, коалиции, выборы (в демократии и гибридном режиме)
- 30 законов: голосование по идеологии партий, лоббирование, взаимоисключающие реформы
- Смена режима: демократия ↔ гибридный режим ↔ автократия
- Политкапитал, указы, усталость от власти, протесты, перевороты и революции

**Геополитика**
- Отношения, дипвизиты, помощь, торговые соглашения, пакты, военные союзы, блоки
- Санкции бьют по экспорту сырья и доступу к рынкам — и по вам самим
- Войны на гексагональной карте: оккупация провинций, союзники, капитуляция, аннексия
- ИИ-страны ведут свою экономику, бюджет, дипломатию и иногда нападают

**События:** засухи, забастовки, скандалы, пандемии, нефтяные шоки, мировые рецессии и др.

## Локальный запуск

Нужен любой статический веб-сервер (ES-модули не работают через `file://`):

```bash
cd public
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Деплой на сервер через Docker

### 1. Установить Docker (если ещё нет)

```bash
curl -fsSL https://get.docker.com | sh
```

### 2. Склонировать репозиторий и запустить

```bash
git clone https://github.com/XSGGH/derzhava.git
cd derzhava
docker compose up -d --build
```

Игра будет доступна на `http://IP_СЕРВЕРА:8080`.
Чтобы сменить порт, поправьте `ports` в `docker-compose.yml` (например, `"80:80"`).

### Без docker compose

```bash
docker build -t derzhava .
docker run -d --name derzhava --restart unless-stopped -p 8080:80 derzhava
```

### Обновление

```bash
cd derzhava
git pull
docker compose up -d --build
```

### HTTPS и домен (по желанию)

Если на сервере уже стоит nginx/Caddy/Traefik, проксируйте домен на `127.0.0.1:8080`. Пример для nginx:

```nginx
server {
    server_name game.example.com;
    location / { proxy_pass http://127.0.0.1:8080; }
}
```

Затем `certbot --nginx -d game.example.com`.
